## CHANGE LOG

### Version 1.1.0 (Nov 2, 2026)
- **Swift Package Manager:** added support for `webengage-ios-sdk` **2.x** (WebEngage iOS SDK **7.x**). The supported range is now `1.0.0 ..< 3.0.0`.
- **CocoaPods:** now depends on `WebEngage/Location` only, so apps no longer pull in unrelated WebEngage modules (such as Inspector, added in iOS SDK 7.1.0).
